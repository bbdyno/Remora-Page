Remora - SSH Client

Your servers, within reach.

Remora is a remote terminal and server access app for iPhone, iPad and Mac. Open a shell, move files over SFTP and forward a port, all from one host list.

features

The everyday SSH toolkit, free to use.

Cards tagged pro need Remora Pro. The rest is in the free version, which has no time limit and no ads.

  • ssh

    SSH terminal

    Open a shell on your server. The free version runs one session at a time.

  • input

    Room for long commands

    A larger key row above the keyboard includes a paste key, and a command editor gives you room to write or paste long commands. Copy from output lists the links, IP addresses and paths found in the terminal output, so you can copy one with a tap.

  • hosts

    An organised host list

    Sort servers into groups and find the one you need with search. Each host can have a command that runs after connecting. The free version saves up to 3 hosts.

  • keys

    SSH key management

    Generate a new ed25519 key in the app, or import the ed25519 and RSA keys you already use in OpenSSH format.

  • known_hosts

    Host key verification

    Remora asks before trusting a server the first time you connect, and warns you if that server's key later changes.

  • sftp>

    SFTP file browser

    Browse remote folders, download and upload files, create folders, rename and delete.

  • snippets

    Saved command snippets

    Save the commands you type again and again, so they are ready when you need them. The free version saves up to 3 snippets.

  • lock

    App lock

    Lock Remora with Face ID, Touch ID or your device passcode.

  • theme

    Themes and font size

    Choose a dark or a light terminal theme and set the font size that suits you. Remora Pro adds more themes.

  • pro

    Unlimited hosts, sessions and snippets

    Save as many hosts and snippets as you like, and keep several SSH sessions open at once in tabs.

  • pro

    Local port forwarding

    Reach a service on the remote side through a local port on your device.

  • pro

    Jump hosts

    Connect to a server through another server when it is not directly reachable.

  • pro

    OpenSSH config import

    Already have an OpenSSH config file? Import your hosts from it.

  • pro

    Automatic reconnect

    Remora reconnects on its own when the connection drops or the app returns from the background.

  • pro

    iCloud sync

    Your hosts, snippets, port-forward rules and known host keys stay in sync across your Apple devices.

privacy

Your servers are none of our business.

Remora has no account system and we run no servers of our own, so there is nowhere for your data to go except where you send it.

  • No account, no sign-up. Install it and add a host.
  • No analytics, ads or tracking. No third-party SDKs that collect data.
  • Stored on your device. Hosts, snippets, forwarding rules and known host keys stay on the device.
  • Secrets in the Apple Keychain. Passwords and private keys are stored in the Keychain on your device, and stay there unless you turn on sync.
  • Direct connections. SSH sessions go straight from your device to the servers you set up.
  • Sync through your own iCloud. If you turn on sync, your data goes to your private iCloud database, and passwords and keys travel through iCloud Keychain. We cannot access it.
