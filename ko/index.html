Remora - SSH Client

내 서버를 손 닿는 곳에.

Remora는 iPhone, iPad, Mac에서 쓰는 원격 터미널이자 서버 접속 앱입니다. 셸을 열고, SFTP로 파일을 옮기고, 포트를 포워딩하는 일까지 호스트 목록 하나에서 해결하세요.

features

매일 쓰는 SSH 도구, 무료로 다 됩니다.

아래 기능은 모두 무료 버전에 들어 있습니다. 사용 기간 제한도, 광고도 없습니다.

  • ssh

    세션 탭이 있는 터미널

    SSH 세션을 여러 개 열어 두고 탭으로 오가며 작업하세요.

  • hosts

    정리가 되는 호스트 목록

    서버를 그룹으로 묶고, 필요한 서버는 검색으로 바로 찾으세요. 쓰던 OpenSSH 설정 파일이 있다면 호스트를 그대로 가져올 수 있습니다.

  • keys

    SSH 키 관리

    앱에서 ed25519 키를 새로 만들거나, 이미 쓰고 있는 OpenSSH 형식의 ed25519·RSA 키를 가져오세요.

  • known_hosts

    호스트 키 확인

    처음 접속하는 서버는 믿어도 되는지 먼저 묻고, 나중에 서버의 키가 바뀌면 경고합니다.

  • sftp>

    SFTP 파일 브라우저

    원격 폴더를 둘러보고 파일을 내려받거나 올리세요. 새 폴더 만들기, 이름 바꾸기, 삭제도 됩니다.

  • snippets

    명령어 스니펫

    자주 치는 명령어를 저장해 두고 필요할 때 꺼내 쓰세요.

  • -L

    로컬 포트 포워딩

    원격지에 있는 서비스를 내 기기의 로컬 포트로 연결해 쓰세요.

  • -J

    점프 호스트

    바로 닿지 않는 서버는 다른 서버를 거쳐 접속하세요.

  • pro

    iCloud 동기화

    Remora Pro를 쓰면 호스트, 스니펫, 포트 포워딩 규칙이 내 Apple 기기끼리 동기화됩니다.

free vs pro

일은 무료 버전으로, 기기 간 동기화는 Pro로.

Pro에 더해지는 기능은 iCloud 동기화 하나입니다. 무료 버전에는 기간 제한이 없습니다.

privacy

내 서버 정보는 내 기기에만.

Remora에는 계정이 없고, 저희가 운영하는 서버도 없습니다. 데이터는 사용자가 직접 보내는 곳 말고는 갈 데가 없습니다.

  • 계정도 가입도 없습니다. 설치하고 호스트만 추가하면 됩니다.
  • 분석 도구, 광고, 추적이 없습니다. 데이터를 수집하는 서드파티 SDK도 넣지 않았습니다.
  • 기기에 저장합니다. 호스트 목록, 스니펫, 포워딩 규칙, 알려진 호스트 키는 기기에 남습니다.
  • 비밀 정보는 Apple 키체인에. 비밀번호와 개인 키는 기기의 키체인에 저장하고, 동기화를 켜지 않는 한 기기 밖으로 나가지 않습니다.
  • 서버와 직접 연결합니다. SSH 연결은 기기에서 사용자가 설정한 서버로 곧바로 이어집니다.
  • 동기화는 내 iCloud로. 동기화를 켜면 데이터는 사용자의 비공개 iCloud 데이터베이스로, 비밀번호와 키는 iCloud 키체인으로 옮겨집니다. 저희는 그 데이터를 볼 수 없습니다.
